Admin Account Setup Guide

To create user accounts manually, edit js/app.js and update the USER_ACCOUNTS array.

{
  username: 'user@example.com',
  password: 'User@123',
  name: 'Full Name',
  phone: '+91 90000 00000',
  address: 'Area, Shirwal'
}

After editing and pushing to GitHub, users can log in using those credentials.
